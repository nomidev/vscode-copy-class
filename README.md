# Copy Java Class

IntelliJ의 **Copy Class(F5)** 처럼 Java 클래스를 다른 패키지(또는 다른 이름)로 복사합니다.

## 사용법

1. 탐색기 또는 에디터에서 `.java` 파일을 우클릭 → **Copy Class...**
2. 새 클래스명 입력 (기본값은 원래 이름)
3. 대상 패키지 선택 - 입력창에 현재 패키지명이 미리 채워져 있어서 바뀌는 부분만 고치면 되고, 목록에서 고르거나 새 패키지명을 입력해도 됨

## 복사할 때 자동으로 처리되는 것

- `package` 선언을 대상 패키지로 변경
- 클래스명을 바꾼 경우 클래스 선언, 생성자, `Foo.class` 같은 자기 참조 등 `package`/`import` 줄을 제외한 모든 곳의 클래스명을 변경
- 원본과 **같은 패키지에 있던 클래스**(import 없이 쓰던 것)를 복사본이 쓰고 있으면 `import`를 자동 추가
  - 주석/문자열 안에만 나오는 이름은 무시
  - 대상 패키지에 같은 이름의 클래스가 이미 있으면 import를 추가하지 않고 경고
- 원본 파일의 인코딩(EUC-KR/MS949 등)과 줄바꿈(CRLF/LF)을 그대로 유지

## 알아둘 점

- 클래스명 변경은 단어 단위 치환이라, 문자열이나 주석 안의 같은 이름도 함께 바뀝니다.
- 원본을 참조하는 다른 파일은 수정하지 않습니다(복사만 하는 기능이라 리팩터링과 다릅니다).
- 소스 루트는 `package` 선언과 파일 위치로 계산합니다. 둘이 어긋나 있으면 중단합니다.
